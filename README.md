# ЖК «Компаньйон», 2 черга

Односторінковий сайт мешканців будинків 31 / 33 / 35 (с. Сокільники, вул. Героїв Майдану).
Він показує, які квартири вже долучилися до спільних ініціатив, скільки зібрано і що вже зроблено.

Стек: React + Vite. Бекенду немає, сайт складається зі статичних файлів і деплоїться на GitHub Pages.

## Локальний запуск

Потрібен Node.js 18+.

```bash
npm install      # встановити залежності
npm run dev      # dev-сервер: http://localhost:5173
npm run build    # продакшн-збірка в dist/
npm run preview  # переглянути збірку локально: http://localhost:4173
```

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` збирає й публікує сайт при кожному push у `main`.
Один раз увімкніть Pages у репозиторії: **Settings → Pages → Source: GitHub Actions**.
Сайт буде доступний за адресою `https://<user>.github.io/zhk-kompanyon-2/`. `base: './'` у `vite.config.js`
дозволяє йому працювати з підшляху.

## Оновлення даних про внески

Таблиця внесків містить персональні дані (ПІБ, телефони, e-mail), тому **її не можна комітити**.
У репозиторій потрапляє лише знеособлений `src/data/units.json`: будинок, під’їзд, поверх, тип приміщення,
номер (як у документі про право власності) та сума, що надійшла.

1. Покладіть свіжу таблицю у папку `private/` (вона в `.gitignore`), наприклад
   `private/ЖК Компаньйон - внески.xlsx`.
2. Запустіть конвертер (потрібен Python 3 і `pip install openpyxl`):

   ```bash
   python scripts/build-data.py "private/ЖК Компаньйон - внески.xlsx"
   # або з явною датою актуальності:
   python scripts/build-data.py "private/ЖК Компаньйон - внески.xlsx" --as-of 2026-10-20
   ```

   Скрипт бере аркуш «Підсумок» (колонки «Сходи», «Шлагбауми», «Решта»), пропускає комори й записує
   `src/data/units.json`. Дата актуальності за замовчуванням дорівнює даті останнього платежу на аркушах
   зборів.
3. Перевірте `git diff src/data/units.json` і закомітьте.

## Що де редагувати

| Що | Де |
| --- | --- |
| Реквізити (зараз **тестові**), посилання на банку | `src/config.js` → `REQUISITES` |
| Ініціативна група, адміністратор | `src/config.js` → `TEAM`, `ADMIN` |
| Що зроблено / у планах | `src/config.js` → `DONE` |
| Що живить резервне живлення, час роботи | `src/config.js` → `BACKUP` (`backupHours`) |
| Питання та відповіді | `src/components/Faq.jsx` |
| Розташування секцій на схемі | `src/components/Complex.jsx` → `LAYOUT` |

## Структура

```
scripts/build-data.py   # xlsx → src/data/units.json (без персональних даних)
src/
  config.js             # усі тексти й налаштування, які часто змінюються
  data/units.json       # знеособлені дані по приміщеннях
  lib/data.js           # підрахунки: по будинках, під’їздах, статусах
  components/           # Hero, Complex (схема ЖК), Analytics, Done,
                        # Requisites, Team, Faq, Footer
```

## Конфіденційність

- На сайті немає ПІБ власників, телефонів, e-mail і коментарів до платежів.
- Ініціативна група вказана лише іменем, прізвищем і телеграмом.
- `.gitignore` блокує `private/`, `*.xlsx`, `*.docx`, `*.csv`.
